# Custom Component

You will add a 5-star rating widget for a numeric score field.

## 1. Write the widget

It receives standard `FieldComponentProps` (`def`, `name`, `value`, `onChange`, `onBlur`, `ref`, `error`, `disabled`, `config`). Use `defineFieldComponent` for typed `value`/`onChange` with zero runtime cost.

```tsx title="examples/custom-component.tsx"
function StarsField({ def, name, value, onChange, error, disabled }: FieldComponentProps) {
  const current = typeof value === "number" ? value : 0;
  return (
    <FieldShell label={def.meta?.label} required={!def.optional} error={error} name={name}>
      {[1, 2, 3, 4, 5].map((star) => (
        <button key={star} type="button" disabled={disabled} onClick={() => onChange(star)}>
          ★
        </button>
      ))}
    </FieldShell>
  );
}
```

Full widget in `examples/src/examples/custom-component.tsx`. Derive required state as `!def.optional`; read `def.meta`, `def.min`/`max`, `def.entries`.

## 2. Register it

`FieldComponentMap` is closed over at factory time — not swappable at runtime. Type-check it with `defineFieldComponents` (zero runtime).

```ts title="examples/custom-component.tsx"
const customSystem = createFormSystem({
  fieldComponents: {
    number: StarsField,
    string: TextField,
  },
  schemaResolver: zodAdapter,
});
```

`createFormSystem` throws when any registered value is not a function.

## 3. Render it

Register the widget under the base kind it handles — validation stays a plain number, only the UI changes:

```ts title="examples/custom-component.tsx"
const schema = z.object({
  score: z.number().min(1).max(5).meta({ label: "Score" }),
  title: z.string().min(1).meta({ label: "Title" }),
});
```

Need per-instance options? Use `config` — it passes through untouched (`<SmartField config={{ options: [...] }} />`).

## Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| `No component registered for field kind "number"` | Kind missing from map | Add `number: StarsField` to the `fieldComponents` passed to `createFormSystem()` |

Agent hint: `makeFieldDef` attaches `meta` and `optional` to the base def (`package/src/adapters/shared/index.ts`).
