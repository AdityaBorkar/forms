# Custom Component

You will add a 5-star rating widget without touching validation or core.

## 1. Write the widget

It receives standard `FieldComponentProps` (`def`, `name`, `value`, `onChange`, `onBlur`, `ref`, `error`, `disabled`, `config`). Use `defineFieldComponent` for typed `value`/`onChange` with zero runtime cost (`package/src/types.ts:123`).

```tsx title="examples/custom-component.tsx"
function StarsField({ def, name, value, onChange, error, disabled }: FieldComponentProps) {
  const current = typeof value === "number" ? value : 0;
  return (
    <FieldShell label={def.meta?.label} required={!def.optional} error={error} name={name}>
      {[1, 2, 3, 4, 5].map((star) => (
        <button key={star} type="button" disabled={disabled} onClick={() => onChange(star)}>
          ★
        </button>
      ))}
    </FieldShell>
  );
}
```

Full widget in `examples/src/examples/custom-component.tsx:24-59`. Derive required state as `!def.optional`; read `def.meta`, `def.min`/`max`, `def.entries`.

## 2. Register it

`FieldComponentMap` is closed over at factory time — not swappable at runtime. Type-check it with `defineFieldComponents` (zero runtime).

```ts title="examples/custom-component.tsx"
const customSystem = createFormSystem({
  fieldComponents: {
    stars: StarsField,
    string: TextField,
    textarea: TextareaField,
  },
  schemaResolver: zodAdapter,
});
```

`createFormSystem` throws when any registered value is not a function (`package/src/core/create-form-system.ts:75`).

## 3. Select it per field

A Component override replaces the base Kind at Adapter time — validation stays a plain number, only the UI changes:

```ts title="examples/custom-component.tsx"
const schema = z.object({
  score: z.number().min(1).max(5).meta({ component: "stars", label: "Score" }),
  title: z.string().min(1).meta({ label: "Title" }),
});
```

`resolveKind` lets a non-empty `meta.component` win (`package/src/adapters/shared/field-def.ts:8`); outer `meta` wins via `mergeMeta`. Need per-instance options? Use `config` — it passes through untouched (`<SmartField config={{ options: [...] }} />`; the combobox reads `config.options`).

## Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| `No component registered for field kind "stars"` | Kind missing from map | Add `stars: StarsField` to the `fieldComponents` passed to `createFormSystem()` |
| Override ignored | `component` empty or not a string | Pass a non-empty string in `.meta({ component: "stars" })` / `v.metadata()` |

Agent hint: `makeFieldDef` applies `resolveKind` and attaches `meta` only when present (`package/src/adapters/shared/field-def.ts:24`).
