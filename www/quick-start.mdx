# Quick Start

You will render two fields straight from a Zod schema with zero per-field wiring.

## 1. Install

```sh
bun add @adistack/forms react-hook-form zod @hookform/resolvers
```

`react@>=18` and `react-hook-form@^7.86.0` are required peers. `zod@>=4` and `@hookform/resolvers@>=5` are optional peers — only needed with the Zod Adapter (`package/package.json:52-58`). Bun only; Node is unsupported.

## 2. Register field components

One component per Kind you render. Each receives `FieldComponentProps` (`def`, `name`, `value`, `onChange`, `onBlur`, `ref`, `error`, `disabled`, `config`).

```ts title="components/form-zod.tsx"
import type { FieldComponentMap } from "@adistack/forms";

const fieldComponents: FieldComponentMap = {
  string: TextField,
  email: TextField,
  number: NumberField,
  boolean: CheckboxField,
  enum: SelectField,
  textarea: TextareaField,
};
```

Full map in `examples/src/components/form-zod.tsx:28-43`. Read schema data from `def` (`def.kind`, `def.meta`, `def.min`/`def.max`, `def.entries`, `def.optional`).

## 3. Wire the factory once

```ts title="components/form-zod.tsx"
import { createFormSystem } from "@adistack/forms";
import { zodAdapter } from "@adistack/forms/adapters/zod";

export const { Form, SmartField, SmartFieldArray, useForm, useFormContext } =
  createFormSystem({
    fieldComponents,
    schemaResolver: zodAdapter,
  });
```

`createFormSystem` closes over `fieldComponents` — it is not in React context and not swappable at runtime (`package/src/core/create-form-system.ts:55`). It throws `createFormError` without a `schemaResolver`, with a missing/empty map, or when any entry is not a function. `SmartField`/`useForm`/`useFormContext` are factory-returned, never direct imports.

## 4. Render from a schema

```tsx title="examples/simple-form.tsx"
import z from "zod";

const schema = z.object({
  email: z.email().meta({ label: "Email", placeholder: "ada@example.com" }),
  name: z.string().min(1).meta({ label: "Name", placeholder: "Ada Lovelace" }),
});

function SimpleForm() {
  const form = useForm({ schema, onSubmit: (values) => console.log(values) });

  return (
    <Form form={form}>
      <SmartField name="name" />
      <SmartField name="email" />
      <button type="submit">Submit</button>
    </Form>
  );
}
```

Flow: `useForm({ schema })` → `buildFieldMap` + `createResolver` (plus your `defaultValues` straight to RHF) → `<Form form>` (`FormProvider` + `{ fieldMap }` context) → `<SmartField name>` → `resolveFieldDef` → `fieldComponents[def.kind]` via `useController` (`package/src/core/use-form.ts:116`, `package/src/core/form.tsx:25`, `package/src/ui/smart-field.tsx:29`).

## 5. Run the demo

```sh
bun run --cwd examples dev
```

Opens `Bun.serve` in `examples/server.ts` on port 4000. See [Concepts](/concepts) for the ten canonical terms, [Field Kinds](/field-kinds) for every dispatch Kind.

## Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| `SmartField must be used within a <Form>` | Rendered outside factory `<Form>` | Wrap with the `Form` from the same `createFormSystem()` call (`package/src/core/form-context.ts:8`) |
| `No field definition found for "x"` | `name` does not match schema | Match dotted path to schema keys; see [Nesting](/nesting) |
| `No component registered for field kind "x"` | Kind missing from map | Add `fieldComponents[kind]`; missing def/component renders `null` + dev-only `devWarn` in `warn`/production mode |

Agent hint: `useForm` caches per schema object in a `WeakMap` — hoist `schema` for O(1) hits (`package/src/core/use-form.ts:111`).
