# API

You will import from the right entrypoint and type against the right shape.

## Entrypoints

4 exports in `package/package.json`. Consumed as source TypeScript — no build step, ESM only.

| Entrypoint | Path | Purpose |
|---|---|---|
| `@adistack/forms` | `src/index.ts` | Core: `createFormSystem`, `resolveFieldDef`, types |
| `@adistack/forms/adapters/zod` | `src/adapters/zod/index.ts` | `zodAdapter` (with `createFieldMap`/`createResolver` methods), standalone `createResolver(schema)` |
| `@adistack/forms/adapters/valibot` | `src/adapters/valibot/index.ts` | `valibotAdapter` (with `createFieldMap`/`createResolver` methods), standalone `createResolver(schema)` (`picklist`/`enum` → `enum`) |
| `@adistack/forms/ui` | `src/ui/index.ts` | Types only: `SmartFieldProps`, `SmartFieldArrayProps`, `SmartFieldArrayRenderProps`, `FieldArrayRow` |

`SmartField`/`useForm`/`useFormContext`/`SmartFieldArray` are factory-returned, not direct imports.

```ts title="app.ts"
import { createFormSystem, resolveFieldDef } from "@adistack/forms";
import { zodAdapter } from "@adistack/forms/adapters/zod";
import { valibotAdapter } from "@adistack/forms/adapters/valibot";
import type { SmartFieldArrayProps } from "@adistack/forms/ui";
```

## FormSystem

```ts title="package/src/core/create-form-system.ts"
createFormSystem({ fieldComponents, schemaResolver, onMissingField }: CreateFormSystemOptions) => {
  Form, SmartField, SmartFieldArray, useForm, useFormContext
}
```

| Member | Shape |
|---|---|
| `Form` | `<Form form={formInstance}>` — `FormProvider` + `{ fieldMap }` context; throws without `form` prop |
| `SmartField` | `{ name: string; disabled?: boolean; config?: Record<string, unknown> }` — `useController` dispatch; throws outside `<Form>` |
| `SmartFieldArray` | Factory-bound (requires `<Form>` context) — `{ name: string; children: (props) => ReactNode }` |
| `useForm` | `(options: UseFormOptions) => FormInstance` — `fieldMap` via `createFieldMap`, `defaultValues` straight to RHF, resolver via `createResolver` |
| `useFormContext` | `() => FormContextInstance` — RHF return + `{ fieldMap }`; throws outside `<Form>` |

`onMissingField: "throw" | "warn"` (default `"throw"`): dev throws fast; `"warn"` or production renders `null` with a dev-only deduped `devWarn`.

## Instance types

Both generic over `TValues extends FieldValues` (default `FieldValues`):

| Type | Meaning |
|---|---|
| `FormContextInstance` | `UseFormReturn<TValues> & { fieldMap: SchemaTree }` — what `useFormContext` returns |
| `FormInstance` | `UseFormReturn<TValues, unknown, TValues> & { fieldMap, onSubmit, onInvalid?, onSubmitError? }` — what `useForm` returns; this is what `<Form>` accepts |
| `UseFormOptions` | `{ schema, onSubmit, onInvalid?, onSubmitError?, defaultValues?, validationMode?, reValidateMode? }` |
| `FormProps` | `{ form: FormInstance; className?: string; children?: ReactNode }` |

Helpers: `defineFieldComponent` / `defineFieldComponents` (identity, zero runtime), `InferFormValues` (Standard Schema inference), `FieldKindValueMap` (typed `value` per Kind), `ComboboxConfig` (`{ options: string[] }`).

## Constraints

| Dependency | Role | Required? |
|---|---|---|
| `react-hook-form@^7.86.0` | Form state, `useController`/`useFieldArray` | Yes (peer) |
| `react@>=18` | UI runtime | Yes (peer) |
| `@hookform/resolvers@>=5` | `zodResolver` / `valibotResolver` bridge | Only with an Adapter (optional peer) |
| `zod@>=4` | Schema + validation | Only with Zod Adapter (optional peer) |
| `valibot@>=1` | Schema + validation | Only with Valibot Adapter (optional peer) |

Invariants: TypeScript strict + `verbatimModuleSyntax` + `noUncheckedIndexedAccess`; alias `#/* → ./src/*`; tests colocated (`*.test.ts[x]` next to source, never `package/tests/`); `jsdom` via `// @vitest-environment jsdom` first line for component tests. Internal errors use `createFormError` (`[@adistack/forms]` prefix); recoverable misses use dev-only deduped `devWarn`.

Agent hint: file map and Adapter internals live in `docs/ARCHITECTURE.md`; full type glossary in `docs/GLOSSARY.md`.
